# Lessons — using the clt MCP and COMSOL on this cluster

Written by whoever (human or agent) learns something worth not relearning.
Loaded at the start of every autopilot session; keep entries short and actionable.
- **resources** — ACOUSTICSBATCH has only 2 seats across all of SEAS, so at most two acoustics batch jobs can run anywhere at once — prefer one internally-sweeping job over parallel ones. _2026-08-19_
- **comsol-api** — Never call mesh.automatic(false): converting to user-controlled first BUILDS the physics-controlled sequence, which fails for eigenfrequency studies. Create mesh features directly instead. _2026-08-19_
- **comsol-api** — Datasets (dset1...) only exist after a study has run — create Derived Values and tables after the first study().run(), never before. _2026-08-19_
- **comsol-api** — appendResult() appends table COLUMNS, not rows: a sweep CSV comes back wide, as repeated (param, value) column pairs. _2026-08-19_
- **comsol-api** — Exported model .java pins periodic conditions and mesh selections to frozen boundary NUMBERS, which break the moment a parameter changes. Rediscover boundaries geometrically with a tiny Ball selection moved to computed points. _2026-08-19_
- **comsol-api** — For a periodic face set, sample points lying IN the boundary plane; curved walls only touch it along lines, so including them makes COMSOL fail with 'could not find destination boundaries'. _2026-08-19_
- **resources** — COMSOL restarts its progress meter for every geometry build, mesh and solve — the last percentage is stage progress, never job progress. Count completed solver blocks instead. _2026-08-19_
- **resources** — Jobs are billed on requested CPUs + memory, not usage. Check job_efficiency after a run: the graphene height sweep used 5.3 GB of 24 GB requested. _2026-08-19_
- **cluster** — Slurm scripts must cd $HOME/... in the body; a relative --chdir resolves against the submission directory and silently runs in the wrong place. _2026-08-19_
- **cluster** — squeue exits NONZERO once a finished job ages out of the queue, so treat a squeue failure as 'ask sacct', not as a transient error. _2026-08-19_
- **mcp** — Prefer one job that sweeps internally over several parallel jobs: it is faster overall, easier to watch, and does not fight for the 2 shared module licence seats. _2026-08-19_
- **comsol-api** — Generated model-Java must contain NO lambdas, nested interfaces or anonymous classes: `comsol compile` emits them as separate Foo$Bar.class files that the batch runner never loads, so the first call dies with "Error running java class. Foo$Bar" — note that references/Snapshots.java's put()/Setter helper has exactly this bug; set each image property in its own try/catch instead. `(job 40655841)` _2026-08-20_
- **mcp** — geom().image().export() and mesh().image().export() SILENTLY write nothing under the MCP's `comsol batch` line (no exception, "frame: ..." still prints, frames/ ends up empty) because it lacks a renderer — add `-3drend sw` to the comsol batch command in server.mjs codeScript() for software offscreen rendering, or re-run the compiled .class by hand with that flag. `(job 40657019)` _2026-08-20_
- **comsol-api** — A geometry object you create but never feed into a Union/Difference is NOT discarded — the default Form Union finalization merges every loose object into the final geometry, so a conditionally-unused helper cylinder silently becomes part of the model (here an unconsumed collar shell widened a dimer channel from r=2.6 to 3.4 mm and turned dom=1 into dom=6); create helper objects inside the same branch that consumes them. `(job 40657019)` _2026-08-20_
- **physics** — Two-band validity on the (w,L) dimer grid has a rule, not a hand-picked list: margin = [min(f0-3k-f_below, f_above-f0-3k)]/k, and thresholding it at margin >= 1 reproduces the repo's 11-point BAD set exactly (excluded 0.19-0.96, kept >= 1.06) — the largest usable coupling anywhere on the grid is 429.6 Hz at w=3.0, L=18, i.e. kappa_max/kappa0 = 1.84. `(job 40657019)` _2026-08-20_
- **physics** — For a kappa-ENCODED strained lattice, beta cancels out of the flake size: (R/l_B)^2 = (4/sqrt3)*eps*R with eps = |dL|max/(l0+2*alpha*w0), so R is set by the reachable coupling CONTRAST alone — and because a compressed bond demands dk/k = +dL/(LAM-dL) (runaway) while a stretched one demands -dL/(LAM+dL) (saturating), the merit figure is eps = up/(1+up) from kappa_MAX, never the symmetric min(down, up); beta only remains a merit figure for a genuinely length-strained lattice. _2026-08-20_
- **resources** — Displacing the cavities costs nothing to mesh: an R=6 flake strained to a 3.0 mm minimum wall meshed to 211,466 elements vs 211,169 for the same demanded kappa field on a rigid lattice (0.14%, inside the ~3% scatter identical geometries show), and R=9 hybrid = 489,064 elements in 68 s / 1.5 GB — aperiodicity and thin walls are never the cost driver, mode count is. `(job 40657019)` _2026-08-20_
- **comsol-api** — Geometry/mesh image export does NOT auto-fit the camera: the object renders at a fixed world scale, so a 4 cm dimer comes out a few pixels wide and a 30 cm flake fills a tenth of the frame. The image feature's "zoomextents" property accepts only "on"/"off" and setting "on" changes NOTHING in batch (there is no graphics window to zoom), and Camera has no zoomExtents() and exposes only projection/orthoscale/position/target/up — so do not fight the renderer: dump mesh.getVertex()/getElem("tri") and draw the picture locally. `feature.properties()` and `getAllowedPropertyValues(prop)` settle questions like this in one cheap probe job (image() has 70 properties, camera() 51). `(jobs 40659524, 40660469)` _2026-08-20_
- **comsol-api** — mesh.getVertex() returns 3 x Nvert coordinates in METRES (the model's SI base unit, not the geometry lengthUnit) and mesh.getElem("tri") returns 3 x Ntri node indices that are 0-BASED — do not subtract 1 the way mphtxt files need; check by summing triangle areas against a known face (a 16x60 mm cut face came out 20.03 cm2 with 0-based indexing and garbage with 1-based). `(job 40661148)` _2026-08-20_
- **resources** — FreeTet element count is reproducible only at fixed -np (identical geometry gave 2195 at 8 CPU vs 2208 at 4 CPU, but reran exactly at 8), and it also shifts ~3% between solids that are topologically identical but built from different CAD parameterisations — so compare element counts only within one -np, and never use them as a geometry-identity test (use getNBoundaries/getNVertices). `(job 40661148)` _2026-08-20_
- **comsol-api** — comsol batch needs -3drend sw on compute nodes: with the default OpenGL renderer, image().export() writes nothing yet still reports success, so a whole run can look fine and produce no frames. _2026-08-20_
